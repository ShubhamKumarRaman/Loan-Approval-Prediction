# Loan Prediction Backend

Backend-only FastAPI project for Loan Prediction System.

## Phase 1

This phase contains the basic FastAPI project skeleton.

## Project Structure

- `app/` contains the FastAPI backend application.
- `app/core/` contains configuration settings.
- `data/raw/` contains the original dataset.
- `data/interim/` contains temporary processed data.
- `data/processed/` contains final processed data.
- `notebooks/` contains Jupyter notebooks for EDA and model training.
- `logs/` contains application logs.
